# Solve360

A crowdsourced issue reporting platform where users can report local problems like potholes, garbage disposal, broken streetlights, etc.

## Features
- User login & registration
- NGO dashboard
- Admin approval system
- Issue reporting with image upload
- Location-based NGO matching
- Voting system
- Donation system

## Tech Stack
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Future Improvements
- AI-based issue classification
- Mobile app
- Real-time notifications
